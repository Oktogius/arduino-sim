# arduino-sim

Simulator Arduino berbasis web yang berjalan langsung di browser.
Proyek ini dibuat sebagai sarana belajar, dikembangkan bertahap dari prototipe sederhana.

## Status

🚧 Tahap awal pengembangan.

## Rencana

- [x] Setup proyek (frontend Vite + TypeScript)
- [ ] Server compile kode Arduino (Python + arduino-cli)
- [x] Simulasi LED berkedip di browser
- [ ] Editor kode dan serial monitor
- [ ] Komponen tambahan (tombol, potensiometer, dll.)

## Struktur

- `frontend/` — tampilan dan emulator di browser
- `server/` — server untuk compile kode Arduino
